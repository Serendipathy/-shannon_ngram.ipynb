# shannon_ngram

Generate English paragraphs by sampling each next word from Google Books n-gram
counts served by the [ngrams.dev](https://ngrams.dev) REST API.

All logic lives in the importable package `shannon_ngram` under `src/`; the
notebook in `notebooks/` only imports and calls it.

Install and usage instructions follow in a later work item.

Data: Google Books Ngram v3 (CC BY 3.0) via ngrams.dev
